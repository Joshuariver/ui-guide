📘 AI란 무엇인가요?▾
인공지능(AI)은 인간의 학습·추론·인식 등을 컴퓨터가 모방하는 기술입니다. ML, 딥러닝, LLM 등이 포함됩니다.
📗 LLM과 생성형 AI의 차이는?▾
LLM은 대규모 언어 모델로 텍스트 생성에 특화. 생성형 AI는 텍스트·이미지·음악 등을 포함하는 더 넓은 개념입니다.
📙 RAG란 무엇인가요?▾
Retrieval-Augmented Generation. 외부 데이터베이스에서 관련 정보를 검색하여 LLM의 답변을 강화하는 기법입니다.

레이아웃 유틸리티
Flexbox — 1차원(가로/세로). 내비바, 버튼 그룹, 카드 한 줄에 최적.
Grid — 2차원. 카드 갤러리, 대시보드 레이아웃에 최적.
Divider — 콘텐츠 구분선. <hr> 또는 CSS border.
Sticky — 스크롤 시 특정 위치에 고정. 헤더·사이드바에 활용.
📌 선택 기준한 방향 정렬 → Flex. 행+열 격자 → Grid. 두 가지를 중첩 사용해도 됩니다.
.flex-row { display: flex; gap: 16px; align-items: center; } .grid-layout { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; } .sticky-header { position: sticky; top: 0; }
